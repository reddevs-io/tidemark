Driving Health Connect on emulators

DetailsOn API 34+ adb install -g grants health permissions; on API 28 they must be granted in Health Connect UI. Health Connect on API 28 has no launcher icon: start it with am start -a androidx.health.ACTION_HEALTH_CONNECT_SETTINGS -p com.google.android.apps.healthdata. Per-app language (cmd locale set-app-locales) only works on Android 13+; on API 28 change the system language. Health Connect activities opened from Tidemark run in Tidemark task, so force-stopping Tidemark closes them.
