Building Health Connect records in tests

DetailsThe public Metadata constructor can't set an id or dataOrigin, and IntervalRecord/InstantaneousRecord are Kotlin-internal. Use TestRecords.metadata(id, packageName), which wraps connect-testing Metadata.populatedWithTestValues, and FakeHealthRepository.timeOf(record). FakeHealthConnectClient doesn't compute aggregates: stub overrides.aggregate / aggregateGroupByPeriod / aggregateGroupByDuration with connect-testing's AggregationResult(dataOrigins, metrics).
