Versioning and release checks

RationaleUsers moving between channels need monotonic versionCodes under the same key.
Detailsgradle.properties holds tidemark.versionName and tidemark.versionCode, bumped by hand. The release workflow fails if the tag is not v+versionName or the versionCode did not increase. One integer sequence covers GitHub and Play.
