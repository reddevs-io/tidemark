Aggregates for charts, no source picker

RationaleAggregates deduplicate by the data-source priority the user already set in Health Connect settings, so the dashboard avoids double counting when several apps write the same metric. A per-metric picker would duplicate that setting.
DetailsDashboard charts use aggregate, aggregateGroupByPeriod and aggregateGroupByDuration. The explorer shows per-record dataOrigin with a filter by source.
