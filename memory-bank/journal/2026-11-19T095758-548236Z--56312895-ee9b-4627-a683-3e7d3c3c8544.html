RationaleWith one module, a half-written file in one stream breaks every other stream's compile, and parallel Gradle runs contend for the same build locks.
DetailsEach Wave 1 child uses isolation worktree from the committed Wave 0 base. Children never commit; the primary session copies each workstream's owned paths back and verifies the merged tree.
