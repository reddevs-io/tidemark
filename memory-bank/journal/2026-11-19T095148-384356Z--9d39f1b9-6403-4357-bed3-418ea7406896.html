CI, signing and release

DetailsGitHub Actions runs lint and unit tests on every PR. A tag push builds a signed APK attached to a GitHub Release plus an AAB for Play. Keystore and passwords live in encrypted GitHub secrets with an offline backup of the keystore. Same applicationId and same signing key on GitHub and Play so users can move between channels; versionCodes must be monotonic across channels. Upload our own key to Play App Signing instead of letting Google generate one.
