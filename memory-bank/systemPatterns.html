System Patterns

Conventions worth repeating · coding, architecture & testing · Updated 2026-11-19T14:13:23.492461Z

Coding Patterns

Code

Every user-facing string in EN and FR: Each feature owns its own resource files (values/strings_<feature>.xml and values-fr/strings_<feature>.xml). No hard-coded user-facing text. Format dates, numbers and units with the current locale.

Code

French name of Health Connect: In French, Health Connect is Connexion Santé. Use that name in every values-fr string and in the French store and policy text.

Code

French typography: French text uses a non-breaking space before : ; ! and ?. The privacy renderer must pass it through unchanged.

Code

Keep privacy docs in step: Any change to permissions, storage or dependencies updates PRIVACY*.md, docs/play/data-safety.md and docs/play/health-declaration.md in the same change.

Code

No script vals named like DSL properties in Gradle KTS: Inside a receiver lambda the receiver own property wins over a script-level val with the same name. Prefix script vals (releaseKeyAlias) instead.

Code

Workflow conventions: Workflows set defaults.run.shell: bash for pipefail, pin third-party actions to commit SHAs with version comments, and Dependabot keeps the pins current.

Code

Tiles read as one TalkBack element: clearAndSetSemantics with title, value and unit, when, and source; tiles containing buttons use mergeDescendants so the button stays reachable.

Architectural Patterns

Architecture

Read-only Health Connect access through HealthRepository: All Health Connect calls go through the HealthRepository interface in the data package. ViewModels depend on the interface, never on HealthConnectClient. Domain models carry SI values (meters, kilocalories, kilograms, bpm, counts) and Instants; the format package converts for display.

Architecture

Exclusive file ownership per workstream: Parallel work follows the dispatch table in .agent/plans/tidemark-v1-implementation.html. A workstream edits only its owned paths; frozen contract files and gradle/libs.versions.toml change only through the primary session.

Architecture

UI opens Health Connect screens through data.HealthConnectIntents: Only the data package references HealthConnectClient; UI code calls HealthConnectIntents.manageData(context) or settings(). T-010 points the other helpers at it.

Testing Patterns

Testing

FakeHealthConnectClient on Robolectric: Repository tests use androidx.health.connect:connect-testing FakeHealthConnectClient on Robolectric. ViewModel tests use a fake HealthRepository with kotlinx-coroutines-test. Physical-device behaviour is covered by a manual checklist: Health Connect not installed, permission denied or partially granted, history permission unavailable (30-day banner), and several apps writing the same metric.

Testing

Building Health Connect records in tests: The public Metadata constructor can't set an id or dataOrigin, and IntervalRecord/InstantaneousRecord are Kotlin-internal. Use TestRecords.metadata(id, packageName), which wraps connect-testing Metadata.populatedWithTestValues, and FakeHealthRepository.timeOf(record). FakeHealthConnectClient doesn't compute aggregates: stub overrides.aggregate / aggregateGroupByPeriod / aggregateGroupByDuration with connect-testing's AggregationResult(dataOrigins, metrics).

Testing

Parallel Gradle builds on one machine: With eight worktrees building at once on a 30 GB / 12-core machine, each agent runs Gradle with --max-workers=2, -Xmx3g and the in-process Kotlin compiler, and never runs ./gradlew --stop, because daemons are shared across worktrees.

Testing

Compose tests use the v2 rules: Use androidx.compose.ui.test.junit4.v2.createComposeRule and createEmptyComposeRule; v1 is deprecated in BOM 2026.09. Under Robolectric call waitForIdle() inside waitUntil for content loaded on Dispatchers.IO.

Testing

Checking that an intent reaches Tidemark: Use queryIntentActivities(intent.setPackage(pkg)). Aliases come back with activityInfo.name set to the alias and targetActivity set to the real activity.

Testing

TestHealthConnectClient wrapper: data tests wrap connect-testing alpha03 FakeHealthConnectClient to add feature status, permission checks, newest-first reads and lookup by id. Inserted records get ids testHCidN and their origin is the package set with fake.setPackageName, not the one in TestRecords.metadata.

Testing

Normalize ICU spaces in formatted-text assertions: Map U+00A0, U+202F and U+2009 to a plain space before comparing formatted text. Robolectric defaults to en-US, which resolves SYSTEM units to imperial.

Testing

Compose text-fit tests use native graphics: Use @GraphicsMode(NATIVE) for tests that measure text; check ellipsis, didOverflowHeight and screen bounds, not didOverflowWidth; use positionInRoot and size because boundsInRoot is clipped by scrolling.

Testing

Field coverage and paging laziness by test: Reflect over record classes public getters and check the extractor emits each; subclass FakeHealthRepository to record page tokens and assert calls[READ_PAGE] counts.

Testing

Render screens to PNG without an emulator: Robolectric @GraphicsMode(NATIVE) with captureToImage() renders Compose and Vico screens for visual checks. Read the Vico API with javap -l on the cached jar.

Testing

Robolectric startActivity resolution: Call shadowOf(app).checkActivities(true) so unresolved intents throw ActivityNotFoundException, and give test intent filters CATEGORY_DEFAULT so startActivity resolves them.

Testing

Device test data with a throwaway seeder: A seeder app kept outside the repo, built in two flavors (Seeder Watch, Seeder Phone) with WRITE permissions granted through adb install -g, writes a year of all eight types plus overlapping steps and stage-less sleep, so two origins exist. Health Connect Toolbox only inserts one record at a time.

Testing

Driving Health Connect on emulators: On API 34+ adb install -g grants health permissions; on API 28 they must be granted in Health Connect UI. Health Connect on API 28 has no launcher icon: start it with am start -a androidx.health.ACTION_HEALTH_CONNECT_SETTINGS -p com.google.android.apps.healthdata. Per-app language (cmd locale set-app-locales) only works on Android 13+; on API 28 change the system language. Health Connect activities opened from Tidemark run in Tidemark task, so force-stopping Tidemark closes them.
